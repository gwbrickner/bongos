### Unverified (why)
- The loaders don't call `elfRelocate` yet (step 3), so a slid kernel hasn't booted. Step 3's BIOS/UEFI kaslr boots are
  the permanent runtime proof, including for the i386 build (verified ad hoc here, not in `make test`).
- Leads for step 3: after ANY `elfRelocate` failure the loader must re-run `elfLoad` before the slide-0 fallback, since pass 2
  can fail part-way (finding 1's detection happens in pass 2). `bootKaslrPickSlide` assumes linkBase == window base
  (true today: kernel.ld asserts `.text` starts at KERNEL_LINK_BASE). kaslr-reloc-check's alt link at +0x1E000000
  leaves 32 MiB, so a kernel over 32 MiB will fail it ("elfParse rejected") until `KASLR_CHECK_SLIDE` shrinks.
