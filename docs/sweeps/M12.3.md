No finding in the parser's memory safety. Specifically checked and proven safe (by reading, then
by the tests below):
- The uint64 offset sums. Every table satisfies `off + len <= size <= 64 MiB` before use, so the
  uint32 locals (`head + 50`, `os2 + 72`, the stored `cmapSub`) can't wrap. `fontAdvLargestFile`
  runs a 64 MiB font whose tables sit in its last bytes.
- Directory records near 4 GiB (`fontAdvDirectoryBoundaries`).
- Format-4 addressing: odd and wild idRangeOffset values, delta wraparound, cp = 0xFFFF, and
  unsorted endCodes (the search always terminates).
- Format-12 group search on unsorted data, and glyph-id overflow.
- Q6 scaling at `INT32_MIN/MAX x UINT32_MAX` (no int64 overflow).
- Metric extremes including -32768.
- NULL, zero-size and short inputs.
- `*f` is zeroed on every failure path (`initAndCheck` checks it for 600k fuzz inputs).

### Tests added
`tests/host/gfx_font_sfnt_adv_test.c` (13 tests). It includes a from-scratch font builder that
writes exact-size buffers with the cmap table last, so ASan sees any read past it.
- `fontAdvBuilderBaseline`
- `fontAdvInitFailureZeroesFont`: 7 failure paths, `*f` pre-filled with 0xA5
- `fontAdvDirectoryBoundaries`
- `fontAdvLargestFile`: exactly 64 MiB, tables in the last bytes
- `fontAdvFormat4MatchesReference`: 60 random sorted segment sets, every codepoint 0..0x10000, against a linear spec reference
- `fontAdvFormat12MatchesReference`: 200 random group sets, boundaries and random codepoints, plus the 0xFFFF+n wrap case
- `fontAdvCmapSubtableBoundaries`
- `fontAdvCmapRankOrderAndTies`: 120 random record orders
- `fontAdvHmtxLocaEdges`
- `fontAdvScaleQ6MatchesReference`: 8 upems, extremes, exact halves and 160k random cases, against an `__int128` reference
- `fontAdvMetricsExtremes`: int16 extremes x 3 upems x 6 sizes, against an independent reference, plus the fallback chain
- `fontAdvMutationFuzz`: seeded, 12,000 mutated fonts plus 1,500 truncated copies, aimed at the directory, head, hhea, maxp, OS/2, cmap records and subtables, loca, hmtx, glyf, kern and GPOS. It checks every GfxFont invariant and the all-zero `*f` on failure. `-DFONT_FUZZ_SCALE=N` scales it for deep runs.
- `fontAdvSymbolRetryRange`
