## Plan
Design by `architect` (consulted 2026-10-01). Decisions: D-166..D-169. Spec: `docs/specs/acpidump.md`.

Core ideas: a pure, host-tested parser core (`kernel/drivers/acpi/acpi-tables.c`) that reads firmware
memory only through an `AcpiPhysOps` callback; the kernel glue (`acpi.c`) reads through temporary
read-only WB KVA mappings (the HHDM does not map RESERVED memory, where BIOS puts the RSDP and every
table), copies every accepted table into kmalloc/vmalloc memory, and keeps the copies. Only after
`acpiInit` succeeds does `pmmReclaimAcpiMemory()` free the recorded ACPI_RECLAIM ranges.
