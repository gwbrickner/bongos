## Plan
Roadmap steps (ROADMAP.md M1.2):
1. `boot/uefi/include/efi/`: our own minimal UEFI headers (base types, `EFI_SYSTEM_TABLE`, Boot
   Services, Simple Text Output, Loaded Image, Simple File System + File Protocol, GOP, RNG,
   config-table GUIDs). Per D-007, hand-written from the spec, no gnu-efi/POSIX-UEFI.
2. `boot/uefi/`: `efiMain` entry that prints `bongOS loader` to ConOut and to COM1 (raw port
   I/O is fine in the loader per ARCHITECTURE §5.5), then halts.
3. `tools/mkimage` (host C): GPT image (ARCHITECTURE §5.1) with protective MBR, 1 MiB BIOS boot
   partition, FAT32 ESP (via `mkfs.fat` + `mtools`), empty root partition. Places `BOOTX64.EFI`
   on the ESP at `/EFI/BOOT/BOOTX64.EFI`.
4. Harness: boot OVMF with the image and assert the serial banner. The existing
   `run-qemu.sh`/`run-matrix.sh` PASS/FAIL protocol (D-053's neighbor, ARCHITECTURE §23) is
   keyed to the kernel's `isa-debug-exit` KTEST protocol, which doesn't exist until M1.3 — this
   milestone has no kernel yet, just a loader that halts. Extending, not rewriting, the harness
   (CLAUDE.md): add a `--expect-serial PATTERN` mode to `run-qemu.sh` that PASSes once the
   pattern appears in the serial log (polling, not waiting for QEMU to exit), independent of the
   isa-debug-exit exit-code path. Logged as a `D-0xx` local decision (build tooling, not an ABI/
   format/security change).

Wiring: replace `mk/image.mk`'s no-op with a real rule building the UEFI loader (PE32+ via the
`x86_64-unknown-windows` clang target + `lld-link`, ARCHITECTURE §3) and invoking `tools/mkimage`.
`mk/test.mk` passes `--expect-serial "bongOS loader"` for this milestone's matrix row (M1.3 will
switch it to the real KTEST protocol once the kernel exists).

Subagents: `qemu-tester` for build+boot iteration; `reviewer` before the PR. **Architect
consulted** (see the 11:15 log entry below): this milestone mints new on-disk-format constants
(D-056's partition type GUIDs), which CLAUDE.md's "architectural choice" rule covers, on top of
implementing ARCHITECTURE §5.1/5.3's already-fixed GPT layout and BootInfo ABI.
