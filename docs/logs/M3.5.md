### 2026-10-03: architect design received (condensed; this is the plan of record)
**Conflicts with binding docs (each needs a D-row + ARCH edit):** C1 ARCH 6.3/D-088 "only archTlbInvalidateKernelRange's body
changes" is wrong: `vmmUnmapKernel` flushes under irqsave `vmmLock` (IF=0), an IPI-and-wait there deadlocks, so the flush
moves to after the unlock. C2 D-074 "NMI always panics": an NMI while another CPU panics means "stop". C3 D-170(c) (vmalloc at
IF=0) only holds while 1 CPU is online; `acpiInit` stays before `smpInit`. C4 AP enters an idle `hlt` loop (no scheduler).
C5 D-081/D-094 "only the accessor changes": stats/shrink/drain/slab double-free check change too.

1. **CpuLocal** (`kernel/include/cpu-local.h`, `CPU_MAX 64`): `self` at offset 0 (`mov %gs:0`), cpuId (dense, BSP=0), apicId,
   `CpuSync sync`, irqDepth, bootStage, stopped, currentThread/idleThread/runQueue (NULL), pointers `pmm/slab/timer` to blobs
   owned by those subsystems, `SmpMailbox mbox`, `ArchCpuLocal arch` (GDT[8], Tss, stack + 3 IST ranges, tscOffset). GS via
   `IA32_GS_BASE`, KERNEL_GS_BASE=0, no swapgs/FSGSBASE. BSP sets GS in `entry.asm` (RIP-relative, before kernelMain); remove
   `mov fs/gs` from load-gdt.asm; stack protector is `-mstack-protector-guard=global` (keep). AP: CpuLocal from pmm, 4x
   `vmalloc(16K)` (kstack + IST1..3; KVA guards). IDT shared: split `trapIdtInit` / `trapIdtLoad`. Per-CPU: irqDepth, backtrace
   stack ranges, `archTrapCatchTryResume` stack check, `trapCatch.cpu` (caught only on the arming CPU), breakpointHits/irq
   counters atomic, panic state (`panicCpu`).
2. **Trampoline:** USABLE memory < 1 MiB is withheld by D-080 and HHDM-mapped. `smpInit` picks the highest 4 KiB page inside one
   USABLE region with 0x1000 <= p, p+0x1000 <= 0x9F000 (SIPI vector p>>12, not 0 or 0xA0-0xBF); none => warn, boot on 1 CPU.
   Source `kernel/arch/x86_64/trampoline/ap-trampoline.asm` (nasm -f bin, org 0), embedded by `ap-blob.asm` (incbin). Page
   layout: code at 0, GDT at 0xE00 (null, code32 0x08, data32 0x10, code64 0x18), data block at 0xF00 (`ApTrampData`: magic,
   claimed, stage, targetApicId, useLeafB, pml4Phys, gdtr, pm32Ptr, lm64Ptr, entry64, stackTop, cpuLocal, kernelCr3). BSP adds
   the page base once after copying. AP page tables: PML4 from pmm DMA32, copy kernel entries 256-511, PML4[0]->PDPT->PD->PT with
   one R-X (no W/NX/G) identity leaf; freed after bring-up. Sequence: 16-bit (cli; APIC-id check vs targetApicId else park;
   `xchg claimed`; lgdt; CR0 = (cr0&~0x60000000)|1; far jmp) -> 32-bit (segs 0x10; CR4 PAE|PGE; CR3; EFER LME|NXE; last write to
   page = stage 3; CR0 PG|WP; far jmp) -> 64-bit (mov ebx,ebx; rsp/rdi/rsi from data; jmp entry64 = `apEntry64`). `apEntry64`
   (`ap-entry.asm`): lgdt of kernel `bootGdtr`, reload CS (retfq), DS/ES/SS=0x10, FS/GS=0 *before* `mov cr3`, then wrmsr GS_BASE,
   KERNEL_GS_BASE=0, align rsp, `call apMain`.
3. **Startup:** start only MADT Enabled CPUs, skip BSP, skip apicId>254 in xAPIC mode, cap CPU_MAX and `cpus=N` (total incl.
   BSP; `cmdlineFindValue` + decimal parser, host-tested; invalid/0 => warn+ignore). `lapicSendIpi(apicId, lo)`: xAPIC wait
   idle/ICR_HI/ICR_LO/wait idle; x2APIC mfence + WRMSR 0x830. INIT 0x4500, SIPI 0x4600|vec, fixed 0x4000|vec, NMI 0x4400. Per AP
   (BSP, IF=1): allocate everything, fill data block, fence; INIT, 10 ms, SIPI, 200 us, (second SIPI if stage==0), 200 us; wait
   <= 1 s for bootStage ONLINE (BSP does its half of TSC sync meanwhile). Timeout: warn with stage numbers, INIT to park, leak
   memory, continue. `apMain` (IF=0, allocates nothing): archCpuInitAp (GDT/TSS/ltr/lidt), `archPatProgramThisCpu()` BEFORE any
   klog, copy EFER/CR0/CR4 from BSP (CPUID-checked), MTRR comparison vs BSP snapshot, `lapicInitAp` (match x2APIC mode, verify
   id), LAPIC timer + heap, TSC sync, publish `cpuTable[id]` + online mask, full local flush (CR4.PGE toggle), bootStage=ONLINE,
   log `smp: cpu N apic-id=X online`, `smpIdleLoop`. kernelMain: `irqInit; sti; timeInit; smpInit(); pmmPrintMeminfo; ktests`.
4. **IPIs:** per-CPU mailbox (`pending` bitmask, `slot[CPU_MAX]` one request per sender, requests on sender stack, `remaining`
   counter). Send: store slot (release), fetch_or pending, ICR, wait remaining==0 (10 s => panic). Handler 0xF0/0xF2:
   `smpDrainMailbox()`. 0xF1 kick (empty). 0xF3 stop: cli, stopped=1, hlt forever (ktest hook may return). Rules: call-function
   and shootdown require IF=1 and irqDepth==0 when >1 CPU online (else panic); fn runs in IRQ context, never allocates or
   IPI-waits; with 1 CPU online run locally with no restriction. Shootdown: `archUnmapPages` no longer invalidates;
   `vmmUnmapKernel` = lock, unmap, unlock, `archTlbShootdownKernel(va,size)`; a fresh 0->1 map needs none (failed/rolled-back map
   does). Local: <=32 pages invlpg else CR4.PGE toggle (mov cr3 doesn't flush G=1). vfree chunks of 64 pages: one IPI round per
   chunk, free frames after.
5. **TSC:** per-AP warp check (alternating under a RawSpinlock, 1000 iterations/20 ms); on warp estimate offset by 16 ping-pong
   rounds (min RTT), `cl->arch.tscOffset`, `timeMonotonicNs` subtracts it, re-check, warn on bare metal. No TSC_ADJUST writes.
   `archTimerSet` uses the raw local TSC. lapicHz/deadlineMode global. Timer heaps per-CPU, CPU-local timers (arm binds CPU;
   cross-CPU cancel/re-arm is panicBug until M4).
6. **pmm/slab:** per-CPU blobs, still under global `pmmLock`/`slabLock` (no lockless fast path). Stats/meminfo sum all CPUs;
   `pmmDrainAllCaches()`. D-085(1): validate under lock, unlock, then `pmmBug`. Slab: `SlabCpu{mags[SLAB_MAX_CACHES]}`; create
   inits all online CPUs' mags, shrink/destroy flush all. Cross-CPU double-free via bufctl states `MAG=0xFFFD`, `FREEING=0xFFFC`
   (free: redzone unlocked; lock, not BUSY => double free, else FREEING; poison; lock; push, MAG). Fix refill overrun
   (`need>0 && count<capacity`, rechecked after relock). IRQ-context alloc: allowed for pmm/slab/kmalloc (D-200), still banned
   for vmalloc/vmm map/unmap/mmio.
7. **Locking:** `irqTableLock`, one ioapic lock (IOREGSEL/IOWIN), rtc lock; timekeeping/LAPIC stay IRQ-disable (per-CPU);
   `irqRouteGsi` targets BSP apic id. lockdep: expect gets `cpu` (armed CPU only); IRQ-safe -> IRQ-unsafe check in lockdep-core
   (new kind `LOCKDEP_REPORT_IRQ_SAFE_UNSAFE`, host-tested). Panic: `panicEnter` cli+xchg; losers `smpParkSelf()` silently; winner
   sets `panicCpu`, `smpStopOthers()` (0xF3, wait 100 ms, NMI stragglers), then prints; NMI on a non-panicking CPU while panic is
   in progress parks quietly. klog `klogHeld` per-CPU; no CPU prefix on log lines (test.mk greps).
8. **Harness:** matrix.conf = uefi 1, bios 1, uefi 4, bios 4; matrix-full adds `uefi 4 3072`, `bios 1 3072`; run-qemu default
   timeout 180 when CPUS>1; test.mk per row: `^\[info\] smp: N cpus online$`, N-1 lines `smp: cpu K apic-id=A online`, zero
   `^\[(warn|error)\] smp:`, SMP_REQUIRED_KTESTS, and on cpus>1 rows `smp: tlb-stress readers=` and `smp: pmm-stress cpus=4`.
9. **ktests / AP work:** `smpWorkRun(mask, fn, arg)` posts work, kicks 0xF1; idle loop `cli; xchg work; if w {sti; run; fetch_sub}
   else {sti; hlt}`. fn runs IF=1, may allocate/IPI-wait, must not KTEST_ASSERT (results go to shared memory, BSP asserts).
