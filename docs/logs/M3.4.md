**Branch:** `claude/resume-bongos-dev-prrfwz` (session-designated; CLAUDE.md's `m3-4-locking` name is overridden) · **Started:** 2026-10-02 · **State:** done (no PR opened, `needs-owner`)

## Summary
Real locks for the kernel: a FIFO ticket `Spinlock` (irqsave and trylock forms, `preemptCount` raised while held, C11
`atomic.h` wrappers), and in debug builds a lock validator that registers lock classes by init site, keeps an
acquisition-order graph, and reports order inversions (with the stored stack of every edge on the existing chain plus the
current stack), recursive locking, IRQ-unsafe use (a lock taken in a hard IRQ and also with IRQs enabled) and unlocking a
lock not held. klog, pmm, vmm, slab, vmalloc and random now use real irqsave spinlocks. The pure validator core and the
ticket lock are host-tested; ktests prove a deliberate A->B/B->A inversion and an IRQ-unsafe lock taken from an IRQ are
reported, and `make test` requires zero unexpected `LOCKDEP:` lines across every existing test. D-183..D-189.
