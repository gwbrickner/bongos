1. Create the directory tree from ARCHITECTURE §2 (with a short README.md in each currently-empty

7. Run the `reviewer` subagent, fix Critical findings, open the PR.

  CLAUDE.md/ARCHITECTURE §4/D-046 explicitly forbid. Plus a long Should-fix list.
- **Changed (Critical):**
  - `mk/branding.mk` now shells out to a new `tools/gen-branding.sh`, which generates
    `BRANDING_H`/`BRANDING_NAME`/`BRANDING_VERSION`/`BRANDING_CODENAME` (no OS prefix), strips
    `\r`, escapes `\`/`"`, and mirrors `release.yml`'s phase math (phase <= 15 -> minor field,
    else minor+15) so the codename lookup is correct past phase 15.
  - `tests/host/framework/test.h`'s guard is now `HOST_TEST_H`.
  - `tests/host/sample_test.c` no longer hardcodes `"bongOS"`; it now includes the generated
    `branding.h` and asserts the three macros are non-empty, so `branding.h` has a real
    consumer and a real test.
- **Changed (Should-fix, all addressed):**
  - `tests/host/framework/test.h`: `TEST(name)` now defines `nameTest`/`nameCase`/
    `nameRegister` (camelCase, and mangled so `TEST(pmmAllocPages)` can't collide with a real
    `pmmAllocPages()` under test); `ASSERT_EQ` compares operands in their own types (only casts
    to `long long` for the printf); every `ASSERT_*` `return`s on failure instead of falling
    through into a possible NULL deref; `ASSERT_STREQ` handles NULL on either side.
  - `tests/host/framework/test.c`: registers tests at a tail pointer instead of prepending, so
    they run (and print) in source order.

  - `mk/image.mk`: no-ops only while `boot/uefi/*.c` and `boot/common/*.c` are both empty;
