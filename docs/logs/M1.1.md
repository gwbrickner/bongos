## Plan
1. Create the directory tree from ARCHITECTURE §2 (with a short README.md in each currently-empty
   directory so git tracks it and explains what lands there and when).
2. Top-level `Makefile` + `mk/*.mk` fragments per component; `branding/` generation to
   `build/include/branding.h`.
3. `make format` / `make format-check` using the existing `.clang-format`, tolerant of there
   being no C sources yet.
4. `tests/host/`: a tiny assert-based host test runner (constructor-registered tests) plus one
   sample test, wired to `make host-tests`.
5. `make image`, `make test`, `make test-full`, `make run`, `make run-bios`, `make debug`,
   `make gdb`: defined and working, with `image`/`test`/`test-full` no-oping cleanly since there's
   no bootable image until M1.2 (per the roadmap note). Wire `test`/`test-full` to
   `tests/harness/run-matrix.sh` against `matrix.conf` / a new `matrix-full.conf`.
6. Verify `make host-tests` and `make format-check` pass locally, then let CI confirm on the PR.
7. Run the `reviewer` subagent, fix Critical findings, open the PR.
