## Plan
Roadmap steps (ROADMAP.md M1.4):
1. Loader: GOP mode selection (ARCHITECTURE §5.5 step 5, plus a `resolution=` override), fill
   `BootInfo.fb`.
2. Kernel `fbcon`: an 8x16 bitmap font (`data/fonts/console.psf`), scrolling and colors, mirrors
   klog.
3. Full `boot.cfg` parser with `[entry]` sections, `timeout`, and `default`. Menu on screen and
   serial (arrow keys + Enter; on serial, number keys).
4. Harness: QEMU `screendump` at the boot menu and after the kernel banner, compared with
   `tools/imgdiff` (introduced here) against reference PNGs.

Design questions to run past the `architect` subagent before implementing (on-disk format +
boot-handoff-adjacent, per CLAUDE.md): the exact `[entry]`-section boot.cfg schema (ARCHITECTURE
§5.2 lists the keys and the three default entries but not per-entry vs. global scoping, or the
`default`/`timeout` key semantics precisely), how the PSF font is embedded and consumed, and the
screenshot-test comparison approach (`tools/imgdiff` threshold/format).
