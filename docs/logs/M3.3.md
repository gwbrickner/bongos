## Plan
Design by `architect` (consulted 2026-10-02). Decisions to record: D-176..D-182 (API/heap, calibration
reference, TSC policy, LAPIC timer, RTC, wall-clock test, 100 ms test policy). Key points: pure core
(`time-core.{h,c}`: mult/shift scaling with `__int128` multiply only, calibration math, civil->epoch, RTC decode,
256-entry (deadline,seq) timer heap) host-tested; portable `timekeeping.{h,c}` (timeInit, timeMonotonicNs,
timeWallNs, timerInit/Arm/Cancel, IRQ-disable sections); arch `clockref.c` (PM timer, HPET 32-bit reads),
`time-x86.c` (TSC policy+calibration, LAPIC timer one-shot or TSC-deadline, vector 0xFE), `rtc.c`.
Roadmap deviation (needs-owner, D-181): the wall-clock test cannot use a cmdline host time (fixed before firmware
runs, baked into the image); instead `run-qemu.sh` timestamps the kernel's `time: wall-check` serial line and
`mk/test.mk` requires |host - guest| <= 2 s. Three M3.2 ktests assume the LAPIC timer is unused and are adapted
(0xFE is the timer's per ARCH 7.2; not a weakening).
