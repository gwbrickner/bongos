### Architect design (consulted 2026-09-29; the source of truth for the sub-steps below)
Measured on the debug kernel: relocs against alloc sections are `R_X86_64_32S` (.text), `PC32`/`PLT32` (.text, need
nothing), `R_X86_64_64` (.rodata/.data/.ktests). No `R_X86_64_32`, no GOT types, no reloc against ABS/UND symbols.
`.rela.*` are non-alloc but the whole ELF (incl. section headers at the end) is in the loader's buffer.
`.ksyms` has no relocs (raw link-time addresses). Linking with `KERNEL_LINK_BASE=0xFFFFFFFF9FE00000` and comparing
with "load + add slide to 64/32S" is byte-identical (proven with a prototype) -> build-time test A6.

**A. Loader relocation** (`boot/common/elf-reloc.c` declared in `elf64.h`; `boot/common/bootkaslr.c` + `include/bootkaslr.h`;
both pure/host-tested; stage2 needs them added to `BIOS_STAGE2_COMMON_SOURCES` in `mk/bios.mk`; new `BOOT_ERR_ELF_RELOC=-20`)
- `BootStatus elfRelocate(const ElfImage*, const uint8_t *file, uint64_t fileSize, uint8_t *dest, uint64_t slide, ElfRelocStats*)`:
  two passes over every SHT_RELA whose target section (sh_info) is SHF_ALLOC: pass 1 validates and writes nothing, pass 2
  applies. Classify sections by type/flags never by name; SHT_REL is an error; sh_entsize==24; sh_link -> SHT_SYMTAB
  (entsize 24); e_shentsize==64, 1<=e_shnum<=256, bounds+overflow checks; NO 64-bit `/` or `%` (use `bootDivMod64`);
  reloc location must lie in the file-backed part of a PT_LOAD; never compute S+A: read the current content and add `slide`.
- Types: NONE skip; `R_X86_64_64` against SEC symbol: `v+=slide` (error on wrap), against ABS/UND skip; `32S` (SEC): sign-extended
  value + slide must still fit int32, write low 32 (ABS/UND skip); `R_X86_64_32`: error for SEC; `PC32/PLT32/PC64`: nothing for SEC,
  **error** for ABS/UND; anything else error. Symbol shndx 0xFFF2/>=0xFF00 or a non-alloc section = error.
  After pass 1 require >=1 reloc applied into an SHF_EXECINSTR target (catches a kernel linked without --emit-relocs).
- `bootKaslrPickSlide(seed[64], span, &slide)`: need=alignUp(span,2MiB); span==0 or need>0x20000000 -> BOOT_ERR_ELF_RANGE;
  slots=((0x20000000-need)>>21)+1; h=0x4B41534C52534C44; for 8 qwords h=mix64(h^le64(seed+8i)) (splitmix finalizer);
  slot=((uint64)(uint32)(h>>32)*slots)>>32; slide=slot<<21. Physical placement is independent of the slide (HHDM alias of the
  kernel is not randomized, "later" per §6.6).
- Wiring (same order in `boot/uefi/handoff.c` handoffRun and `boot/bios/stage2/handoff.c`): gather the random seed right after
  elfParse (was after the load); elfLoad; `slide=0`; if `entry.kaslr`: pick + elfRelocate(dest); on any error slide=0 and log
  `loader: kaslr: disabled: <status>; base=0x...`; success logs `loader: kaslr: slide=0x%016 base=0x%016 relocs=%u`;
  kaslr off logs `loader: kaslr: off (boot.cfg); base=0xffffffff80000000` and never calls elfRelocate. UEFI: FreePool(kernelBuf)
  moves after relocation. Add `loaderSerialWriteHex64()` to `boot/common/hw/serial.c`. `BootPtPlan.slide` -> `ptMapElfImage`;
  `BootHandoffFields.kaslrSlide` copied by `bootHandoffFillInfo`; `entryVa = entry+slide`, `kernelVirtBase = linkBase+slide`.
- Pitfalls: relocate `dest` never the file buffer, only after elfLoad; i386: use `bootPhysToPtr()`, no `(uintptr_t)` cast of
  u64 (-Wshorten-64-to-32); run `make image` after each change (host tests miss libcalls).
- **A6 build-time check:** `tools/kaslrcheck/main.c` (host tool from boot/common elf.c, elf-reloc.c, bootmem.c, boot-status.c);
  `mk/kernel.mk` relinks `kernel.alt.elf` from the same objects with a sed'ed copy of kernel.ld (KERNEL_LINK_BASE
  0xFFFFFFFF9E000000; fail unless exactly 1 line substituted); tool relocates kernel.elf by 0x1E000000 and requires a
  byte-identical image with the alt link and `alt.entry == entry+slide`. Target `kaslr-reloc-check`, prerequisite of `test`
  and `test-full`.

**B. Kernel:** `kernelSlide()` inline in `sections.h` = `kernelImageStart - BOOTINFO_KERNEL_WINDOW_BASE` (no BootInfo; panic safe).
KSYM blob stays link-time: add pure `ksymDecodeLookupSlid(blob,size,addr,slide,name,cap,&symAddr)` in `ksym.c` and use it in
`ksymSymbolize` and `backtrace.c printFrame`; `backtracePrint` first prints `  kaslr slide 0x%016llx (link address = address - slide)`
(must not start with `  #`). `bootInfoCheckHeader`: add `kaslrSlide <= 0x20000000 - alignUp(kernelSize,2MiB)` (+ corrupted-header
host test). Log after `stackGuardInit`: `[info] kaslr: virtBase=0x%016llx slide=0x%016llx`. No change: kernel.ld, entry.asm, GDT/IDT,
.ktests, UBSan, canary, W^X verifier, archPagingBuildKernel. BUG_HUNTING gdb note: `symbol-file kernel.elf -o 0x<slide>` or use kaslr-off image.

**C. RNG (D-122):** `libs/crypto/{chacha20,sha256,wipe}.c` + `libs/crypto/include/crypto/*.h` (added to KERNEL_C_SOURCES, `-Ilibs/crypto/include`,
host tests): `chacha20Block(key,ctr32,nonce,out[64])`, `chacha20Xor` (STATUS_ERR_INVALID on counter wrap), `sha256Init/Update/Final`, `cryptoWipe`
(volatile + asm barrier). `kernel/core/random-core.c` (pure: pool/reseed/DRBG on a `RandomState`) + `kernel/core/random.c` (global, lock via
`archIrqSave/Restore`, hw sources). `archHwRandomSeed64`(RDSEED 64 tries)/`archHwRandom64`(RDRAND 10 tries) in `kernel/include/arch/cpu.h` +
`kernel/arch/x86_64/`, CPUID.07H:EBX[18] / CPUID.01H:ECX[30], reject all-zero/all-ones. Pool = running SHA-256 (domain "rng-pool-v1");
`randomAddEntropy` = update + pending+=n (no crediting, never blocks); `reseed`: absorb 4 RDRAND words+rdtsc, d=final(pool),
key=SHA256("rng-reseed-v1"||oldKey||le64(gen)||d), gen++, restart pool, wipe. Fast key erasure: blocks ctr 0..k under the OLD key first (zero nonce),
newKey=blk0[0..32), out=blk0[32..64)||next blocks (<=512 B/step); then key=newKey, wipe. `randomGetBytes(out,n)`: panic if unseeded; reseed if pending>=32;
steps under the lock. `randomU64`, `randomGeneration`. Code rules: add/xor/rotate only, byte-wise loads via `(uint32_t)p[3]<<24`, no FP.
Seed lifecycle in kernelMain: `stackGuardInit(bi)` (D-077 unchanged) -> `randomInit(bi->randomSeed)` (noinline; domain string, 64-byte seed, rdtsc, 8 RDSEED words
w/ RDRAND fallback; logs `random: seeded (hw words n/8 via RDSEED|RDRAND|none)`, WARN if 0) -> `cryptoWipe(bi->randomSeed)` before `vmmInit` ->
existing bootInfoCopy wipe stays -> **drop D-089's carve-out**: `pmmReclaimLoaderMemory(void)` reclaims+zeroes the BootInfo page too (D-123; update
`loader_reclaimed` ktest: BootInfo page must now NOT be RESERVED when >= 1 MiB).
Vectors must be copied from the RFC/FIPS text, never typed from memory. Host tests: ChaCha20 RFC 8439 §2.1.1, §2.3.2, §2.4.2, A.1, A.2; SHA-256 "", "abc",
448-bit msg, 1M 'a'; DRBG KAT. ktests: `chacha20_rfc8439_block`, `chacha20_rfc8439_encrypt`, `sha256_fips180_vectors`, `random_drbg_fast_key_erasure`,
`random_add_entropy_reseeds`, `random_sanity` (64 KiB, integers only: monobit |ones-262144|<=3620, transitions |t-262143|<=3620, byte chi-square
S=sum (c-256)^2 in (100*256, 600*256), consecutive 64-byte outputs differ).

**D. Harness:** `tests/harness/kaslr-check.sh --fw uefi|bios`: 4 boots of build/bongos.img; each must show the loader slide line and
`^\[info\] kaslr: virtBase=0x[0-9a-f]{16} slide=0x[0-9a-f]{16}$`, virtBase-slide==0xffffffff80000000, slide 2 MiB aligned <=0x1FE00000, loader slide == kernel slide;
>=2 distinct slides among 4 (false-fail 6e-8). Then boot new `build/bongos-kaslroff.img` (`tests/harness/kaslr-off-boot.cfg`: `kaslr = off`,
`cmdline = ktest=all`): exit 33, loader `kaslr: off` line, kernel line with slide 0, `KTEST PASS kaslr_slide_consistent`. Wire into `make test` and `make test-full`.
`kernel/test/kaslr_test.c`: `kaslr_slide_consistent`, `kaslr_relocs_applied` (self-pointers in .rodata/.data; `mov $sym` vs `lea sym(%rip)`),
`ksym_slide_accounted`. `M26_REQUIRED_KTESTS` in `_check-ktest-pass` (all ktests above + kaslr ones) plus greps for the loader `slide=` line,
the kernel `kaslr:` line and `random: seeded`. GUI: never draw KASLR text on the framebuffer, never add boot.cfg menu entries.
