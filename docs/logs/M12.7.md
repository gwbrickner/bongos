## Summary
Adds JPEG and GIF decoders to `libs/gfx`. JPEG: baseline, extended-sequential and progressive
Huffman files, 8-bit gray/YCbCr/RGB, every sampling factor 1..4, restart intervals, up to 128 scans,
with an exact integer pipeline (islow IDCT, replicated chroma, libjpeg fixed-point YCC) so output is
bit-identical on every host, a strict-by-default error policy, and a memory budget checked exactly
before anything image-sized is allocated. GIF: 87a/89a with a streaming animation compositor
(`gfxGifOpen/NextFrame/Rewind/Close`, constant memory whatever the frame count), transparency,
disposal 0-3, interlace, loop count, and hardened LZW. `gfxImageDecode` sniffs both. Checked against
independent pure-Python encoders (no bitstream parsing in the oracle) with exact comparison, 412
fixtures, truncation at every offset, fuzzing, allocation sweeps, a differential GIF model, structured
random JPEGs and a golden image. 33 new host tests; decisions D-160..D-165. Host-only: no kernel or
boot change.

## Plan
Design comes from the `architect` consult (2026-09-30); decisions D-160..D-165 are written to

Key points:
- **API** (append-only to `gfx-image.h`): `gfxJpegDecode`, `gfxGifDecode` (frame 0 composited),
  and a streaming GIF animation API `gfxGifOpen/GetInfo/NextFrame/Rewind/Close` (one W x H canvas,
  memory independent of frame count). `gfxImageDecode` sniffs `FF D8 FF` and `GIF87a/89a`.
- **JPEG:** SOF0/1/2, Huffman, 8-bit, gray/3-component (YCbCr or RGB by JFIF/Adobe/ids rule); CMYK,
  arithmetic, 12-bit, lossless UNSUPPORTED. Any sampling factors 1..4, restarts, <=128 scans.
  Strict: EOI required, exact RSTn, no resync. Exact pixel pipeline: LLM "islow" IDCT (13/2 bits,
  int64), replicate upsampling by integer mapping, libjpeg 16-bit fixed YCC, clamp. Whole-image
  int16 coefficient buffer for every mode, exact budget pre-check at SOF (before allocating).
- **GIF:** 87a/89a, LZW min code size 2..11 (1 is INVALID), deferred clear, interlace, GCE
  transparency, disposal 0..3 (4..7 = 0), NETSCAPE loop count, frames clipped to the canvas,
  transparent background, index >= palette draws opaque black, trailer required.
- **Tests:** independent pure-Python oracles (`gen_jpeg.py`, `gen_gif.py`, stdlib only: own
  encoders + exact integer model computed from the encoder's coefficients, NOT by parsing the
  bitstream), separate containers (`jpeg-fixtures.z`, `gif-fixtures.z`; `decode-fixtures.z` is not
  touched), exact match (tolerance 0), truncation at every offset, mutation fuzz, allocation
  failure sweeps, exact-peak budget tests, and a manually promoted golden (D-147).
- Shared files touched: `gfx-image.h`, `image.c`, DECISIONS.md (append), ARCHITECTURE §19 (one
  clause), `libs/gfx/README.md` line 1, `tests/host/README.md` (append). Nothing else.
